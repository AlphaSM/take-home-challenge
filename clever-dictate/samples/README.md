# Sample audio (for STT pipeline testing)

These files are used by `scripts/test-stt.mjs` to exercise `POST /api/stt`
(and the full audio → STT → cleanup pipeline) against real WAV files, not just
synthetic ones.

## Files

### `fixture-1s.wav`
- **Provenance**: synthetically generated locally by `scripts/gen-fixture-wav.mjs`
  (a 1-second, 440Hz sine wave, 16kHz mono PCM16). No network access required.
- **License**: N/A — generated by this repo's own script, not downloaded content.
- **Purpose**: guaranteed-offline fixture that always exists, even with no
  internet access, so `test-stt.mjs` always has at least one input to run.

### `OSR_us_000_0010_8k.wav`
### `OSR_us_000_0011_8k.wav`
- **Provenance**: downloaded from the "Open Speech Repository" (OSR) American
  English 8kHz Harvard-sentence recordings, mirrored publicly at
  `https://www.voiptroubleshooter.com/open_speech/american/`. These are
  standard, widely used, freely redistributable speech test clips (used across
  the VoIP/codec-testing community for decades) consisting of a narrator
  reading Harvard/IEEE test sentences.
- **License**: distributed by the source site for free reuse in speech/codec
  testing; no additional restriction is stated by the mirror. Treated here as
  public test audio, used only for local development/testing purposes.
- **Purpose**: real human speech, real WAV encoding, to prove the STT route's
  WAV-header parsing (duration calculation) works against files it didn't
  generate itself.

## Note on transcripts

The mock STT provider (`src/lib/ai/mock.ts` `mockStt`) does not actually
recognize speech — it optionally accepts a `hint` field (ground-truth text)
which it echoes back as the "transcript". This lets `test-stt.mjs` prove the
full pipeline (audio bytes in → STT stage → LLM cleanup stage) works
end-to-end and deterministically, without requiring a real speech model or
network access. See the `SttProvider.transcribe` doc comment in
`src/lib/ai/types.ts` for details.
